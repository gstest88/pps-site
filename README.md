# Philadelphia Plumbing Services

A premium commercial website for Philadelphia Plumbing Services built with Next.js, TypeScript, and Tailwind CSS.

## Goals

- Fast
- Accessible
- SEO-focused
- Conversion focused
- Highly maintainable
- Data-driven architecture

## Tech Stack

- Next.js App Router
- TypeScript
- TailwindCSS
- Lucide React
- ESLint

## Project Structure

app/
components/
lib/
public/

## Development

npm install

npm run dev

## Philosophy

Reusable components.

Typed data.

Minimal duplication.

Professional UI.

Everything is built to scale.
